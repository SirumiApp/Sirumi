# Especificaciones por módulo

Cómo usarlas con Claude Code:
1. Antes de empezar un módulo, pídele: "Lee docs/reglas-de-calculo.md y docs/specs/0X-....md. Primero escribe las pruebas de las reglas que usa este módulo con los ejemplos del documento, después construye las pantallas."
2. Cuando termine, revisa en tu celular con Expo Go y compara con el prototipo.
3. Si cambias una regla, actualiza primero `docs/reglas-de-calculo.md` y luego la prueba.
